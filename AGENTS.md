# Notes for AI coding agents

This project uses Next.js 16, which has breaking changes compared with older versions: APIs, conventions and file structure may differ from your training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing any code, and heed deprecation notices.

Automatic regeneration of this file is turned off (`agentRules: false` in `next.config.ts`) so it stays free of em dashes, matching the rest of the project.
